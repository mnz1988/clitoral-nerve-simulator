How this checklist works
  • Complete means three things: status is Done, the verification checks were run and passed, and the expert review is done where one is required.
  • Two failed attempts, then stop. Log each failed attempt. The second attempt must change something (approach, model or effort). After two, the step is blocked until you decide: fix it by hand, change the approach, or drop the step.
  • Expert review boxes are ticked by you, after a named person has answered the question shown in the step. An AI answer does not count.
  • New problems and changes go into an amendment (bottom of this page). An amendment is then folded into docs/amendments.md, the blueprint and steps.js.
  • Model and effort are starting recommendations. Lower them when a step proves easy; raise them only after a failed attempt.
  • Saving: changes are kept in this browser. Press Export, save the file over checklist/progress.js, and commit it so the state travels with the repository.

Amendments: new problems and changes to the plan

Use this when a step turns up a new subject, a wrong assumption or a problem the blueprint does not cover. Drafts are exported with your progress.
