# References: papers and data we read or use

Written 2026-11-14. This list replaces publishing the PDFs: the PDFs are publisher copyright and stay in the git-ignored folder `downloaded-manually/` (CLAUDE.md rule 7). Anyone can fetch each paper from the link below; a DOI link opens the publisher page, and open-access papers show the full text there.

Status column: **read** = the PDF or full text was read by us; **abstract** = only the abstract was read; **not obtained** = cited but we do not have it. Citations were confirmed against OpenAlex on 2026-11-13 or 2026-11-14 unless marked *unverified*.
