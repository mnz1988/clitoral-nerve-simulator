# Fibre population definitions

One CSV file per population, with columns `x, y, z, diameter, type` (blueprint section 14).
Units: micrometres. `type` is a fibre-model name (for example `MRG`, `Tigerholm`).
Each file's header comment (a line starting with `#`) states the source of its numbers and whether
each is measured, literature or assumption (see `CLAUDE.md`, rule 3).

No populations exist yet; they are made in checklist step 3.3.
